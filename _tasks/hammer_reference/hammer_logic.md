### 2. 战斗公式

- **基础伤害 = 攻² / (攻 + 3.5 × 防)**（`L/HammerUtils.lua:3606-3611`）。怪打人、人打怪、人打人都走这条（怪打人：`S/Player/HammerPlayerGameAttr.lua:39-68`、`L/HammerUtils.lua:3614-`）。这个式子是一次齐次的：双方属性同乘 k，伤害也乘 k。
- 一波飞剑结算顺序（`S/Actor/HammerWeaponInst.lua:148-196`）：基础伤害 × 攻击模式倍率 → ×(1+共鸣增伤) → 先天气运元素附伤（攻×比例，单独一跳）→ 暴击 ×(1+暴伤) → ×(1+增伤) → 概率增伤 → 按最终伤害吸血。
- 攻击模式倍率 / 索敌半径（`L/HammerConfig.lua:124-127`）：弧斩 0.9×0.25 = 0.225、22 米；突刺 0.25、18 米；环绕 0.125、8 米。**每柄飞剑各打一份**，所以法宝槽数是乘区。
- 暴击（`S/Actor/HammerWeaponInst.lua:252-269`）：千分之一精度掷骰；**抗暴、抗爆伤、抗增伤、抗吸血只在目标是玩家时生效**（`:257、:274、:284`）——这几条抗性纯粹是 PvP 属性。
- 玩家基础：暴击 5%、暴伤 +50%、吸血 5%、增伤 0、攻速 0（`S/Global/HammerPropertyCfgMgr.lua:10-18`）。
- 自动攻击：每种模式基础 CD 2 秒，间隔 = 2 / (1 + 攻速 + 共鸣攻速)，最低 0.2 秒；**攻速有效值钳在 [0, 0.5]**（`S/Actor/HammerBattleMgr.lua:22-29, 351-369`；`S/Actor/HammerAttrMgr.lua:689-717`）。锁定目标超出搜索半径就「hold」、超出最大半径就丢（`:452-470`）。
- 战力 = (生命×10 + 攻×25 + 防×50) × (基础比例 + 暴击率 + 抗暴 + 爆伤 + 抗爆伤 + 增伤 + 抗增伤 + 吸血 + 抗吸血)；角色基础比例 0.5、单件装备 1.0（`L/HammerUtils.lua:2425-2455`）。战力直接卡突破。
- **PvP 没有任何伤害封顶**：受伤入口只检查双方 `CanBattle` 权限（`S/Actor/HammerActorHurtMgr.lua:154-209`，PvP 判定 `:174-176`；`L/HammerUtils.lua:2857-2875`）。PvP 只在 PK 区开（`L/HammerConfig.lua:103-`），进区倒计时 5 秒才开打（`S/UI/HammerUIPVP.lua:13-14`；`S/Actor/HammerBattleMgr.lua:309-333`），出区立刻关；击杀全服广播（`S/Actor/HammerActorHurtMgr.lua:103-115`）。`HammerPVPMgr.lua` 是个空壳（4 行）。

### 3. 怪物数值

普通怪按**等级**取整表，不按种类（`S/Global/HammerPropertyCfgMgr.lua:68-123`，`monster.normal`）：

| 等级 | HP | 攻 | 防 | exp |
|---|---|---|---|---|
| 1 | 2000 | 200 | 100 | 20 |
| 4 / 6 / 9 | 3500 / 5000 / 7000 | 350 / 500 / 700 | ½攻 | hp/100 |
| 11 / 19 | 2 万 / 9 万 | 2000 / 9000 | ½攻 | |
| 21 / 29 | 15 万 / 60 万 | 3 万 / 12 万 | ½攻 | |
| 41 / 49 | 640 万 / 2880 万 | | | |
| 129 | 3.9e14 | | | |

规律：前 20 级 攻 = HP/10，21 级起 攻 = HP/5；防 = 攻/2；exp = HP/100。**每个 10 级段 HP 约 ×8**（11→21 是 ×7.5，31→41 起稳定 ×8），段内 1→4→6→9 约 ×1.4~1.75 一档。区域只配 4 个等级（x1 / x4 / x6 / x9），等级范围都写成 `{n,n}`，即**一块区域就一个等级**。

区域独占首领 / 稀有灵宠（`breakthroughBoss`，`S/Global/HammerPropertyCfgMgr.lua:125-183`），和同等级普通怪比：
- Lv9 首领 HP 2.5 万 / 攻 1250（普通 7000 / 700）→ HP ×3.6、攻 ×1.8；Lv19 ×2.8 / ×1.4；Lv29 ×4.2 / ×2.1；Lv49 ×4.9 / ×2.4。exp ×1.4~1.8。
- 没配专属属性的独占怪：等级取区域上限、**exp ×5**（`S/Global/HammerMonSpawnMgr.lua:105-107, 175-177`）。
- 稀有灵宠怪（如 Lv5 雾鹿崽 1.25 万 HP，攻防各 625）：比同区普通怪厚，是「捕捉」目标。

怪的攻击：普通世界怪**不挂**脚本攻击模块（`S/Global/HammerMonSpawnMgr.lua:71` 被注释掉），用引擎近战，命中后改按攻防公式结算（`S/Player/HammerPlayerGameAttr.lua:39-68`）。模块默认值（首领类用）：射程 3.5、出手前摇 0.5 秒、CD 1.5 秒（`S/Actor/HammerMonAtkModule.lua:4-6`）。
**实际威胁很低**：Lv1 怪（攻 200）打 Lv1 玩家（防 500，HP 2500）一下约 20.5，要 120 下才死；玩家一柄剑一下约 167，打 Lv1 怪 12 下。这是挂机游戏的取向。

### 4. 顿悟（每日爆发经验）

`S/Player/HammerPlayerEpiphany.lua`，参数 `L/HammerEpiphanyCfg.lua:11-63`：
- 只统计**怪等级 ≥ 玩家等级 −20** 的击杀（`L/HammerEpiphanyCfg.lua:12`；`S/Player/HammerPlayerEpiphany.lua:201-210`）。
- 当日累计有效击杀到达阈值就触发一次：30、60、100、140、180……880、980……4780、5780……23780，共 50 次（`L/HammerEpiphanyCfg.lua:46-52`）。每天 0 点重置。
- 每次顿悟经验 = **当前等级升级所需 × 1% × 悟性/100**（`L/HammerEpiphanyCfg.lua:22-23`；`S/Player/HammerPlayerEpiphany.lua:254-267`）。悟性丹按次数生效，每次顿悟消耗 1 次（默认 10 次）。
- **追赶**：比全服最高等级低 20 级以上时，当天再加 50 次（阈值 45、80、120……25140），和普通次数交错触发；全服最高等级每天只拉一次并锁定（`L/HammerEpiphanyCfg.lua:17-20, 55-62`；`S/Player/HammerPlayerEpiphany.lua:86-104, 169-182`）。
- 换算：基础 50 次顶满 = 当天多拿 50% 级经验（悟性 100 时），追赶再多 50%。

## 二、刷怪系统细节 vs 我们的营地

### Hammer：玩家插旗「聚灵」现刷

**没有常驻怪。** 野外怪只在玩家扔出「灵幡」后围着灵幡刷出来，到时自动消失。

1. **区域**（`S/Global/HammerMonAreaMgr.lua:38-1531`）：按场景（森林、花海、蘑菇林、沙漠、岩山、雪山、火山、鬼岛、问天长阶……）手摆的长方体，普通区一块约 90×100 米，首领区约 35×35 米，彩蛋区约 30~60 米。每块写死：
   - `priority`（区域重叠时取高的，`S/Player/HammerPlayerScaner.lua:380-401`）；
   - `num = 10`（几乎全部都是 10，主城是 1）；
   - `monsterGroup`：普通怪权重 975~990、稀有灵宠 10~25（彩蛋区 9999 : 1，海岛 999999 : 1），首领区独占首领 990 : 普通 10；
   - `aliveTime`：普通 60 秒，灵宠 / 首领 300 秒；
   - `levelRange = {n,n}`（单一等级）。
   - 每次扫描最多刷 4 只（`scanSpawnCfg.default.maxSpawnNumEach = 4`，`:40-44`）。
2. **灵幡（扫描器）**（`S/Player/HammerPlayerScaner.lua:116-140, 201-251, 319-335`）：
   - 冷却 10 秒；持续 `scanTime` 50 秒（灵幡法宝可改，`:539-550`）；
   - 每 5 秒扫一次，间隔 = 5 / (1 + 扫描速度)，最短 0.1 秒（`:188-199`）；开场先扫一次，所以一面幡共 11 跳；
   - 刷怪半径 10 米；**人离幡超过 15 米就中断**（`:128, 319-329, 601-611`）；传送也中断。
3. **每一跳**（`S/Global/HammerMonSpawnMgr.lua:127-183`）：
   - 数幡周围 ±10 米立方体里的「可战斗目标」（排除灵宠、NPC、福袋、赛道灵宠；**别人刷的怪也算**，`L/HammerUtils.lua:2894-2914`）；
   - 补到 `num`（10）为止，单跳最多 4 只；
   - 加权抽怪，同一批里独占怪、灵宠各最多 1 只；灵宠权重 × (1 + 扫描幸运)（`:195-265`）；
   - 落点：幡周围按 5 米网格从上往下打射线，取落在区域里的地面点再随机挑（`:267-298`）；
   - 等级：配了专属属性用专属等级，独占怪取区域上限，其余在范围里随机（`:171-180`）。
4. **怪的生命周期**（`S/Actor/HammerMonster.lua`）：
   - `aliveTime` 到了直接 Despawn，**不管有没有在打**（`:205-221`）；
   - 拴绳：离开刷出它的区域（或同场景同优先级以上的区域）1 秒后，**瞬移回出生点并回满血**（`:121-177`）；独占怪不能离开区域；
   - 重进地图时，从地图缓存恢复的旧怪一律删掉（`:46-60`；`S/Global/HammerMonSpawnMgr.lua:333-337`）；
   - 独占首领按区域登记，**同一区域同时只有一只**（`S/Global/HammerMonSpawnMgr.lua:300-331`）。
5. **归属**：怪的 `owner` = 插幡的人。**掉落给插幡的人**（`S/Actor/HammerMonster.lua:223-261`），**经验给击杀者**（经 `PlayerDefeatActor`，`S/Actor/HammerActorHurtMgr.lua:135-140`；`S/Actor/HammerBattleMgr.lua:472-501`）。灵宠怪头顶标「专属」。
6. **多人共用**：没有区域人数上限，也没有「一个区域谁来建」的概念（迷你世界服务端权威）。10 只的上限是按**幡周围 10 米**数的，不是按整块区域，所以两个人在同一块 90 米的区域里分开插幡，各自都有 10 只；两面幡挨着就共用这 10 只。
7. **按距离加载 / 卸载**：脚本里没有，交给引擎的区块加载；靠「60 秒寿命 + 人离幡 15 米就停刷」控制总量。

**吞吐**：一面幡 11 跳 × 最多 4 只，场上同时 ≤10 只；配合 22 米自动索敌，等于站桩刷一个 20 米的圈。

### 我们：固定营地（`ISO/raid_camps.gd`）

- 32 米网格（3456/32 = 108，循环世界首尾相接），每格按固定种子抖一个点，各区域有点的概率 0.36 / 0.52 / 0.36 / 0.34 / 0.36（`:23-26`）；
- 小怪 3~5 只一群、巨汉 1~2 只，一成是精英点（精英 + 2 只随从）（`:27, 120-143`）；
- 死后按世界时钟 75 秒复活，精英 150 秒（`:26, 157-163`）；对手修士杀的 12 秒就回（`:35`）；有人站在 35 米内先不复活（`:31, 316-318`）；
- 100 米内建、150 米外且都闲着就收、急飞（水平速度 > 30）时 45 米外闲着的收，急飞时不建（`:28-33, 230-251`）；
- 同屏上限 22 / 手机 20，联机时身边别人名下营地的木偶也占名额（`:292-296`；`G/raid_manager.gd:1524-1526`）；名额满了先把身后最远的闲营地收掉（`:299-314`）；
- 联机：离得近、没在急飞的人里编号最小的建，撞车时编号大的悄悄让出（`:180-210`）；
- 拴绳在 `ISO/raid_mob.gd:27, 832-836`：LEASH 70 米（首领 140）或离人 90 米就回 IDLE、走回点上；**回去时不回血**。

**密度对比**：我们 100 米半径约 31 格 × 0.36 ≈ 11 个营地 × 平均 3.6 只 ≈ 40 只，被 22 的上限截住，均匀铺满整片；Hammer 是 20 米的圈里挤 10 只，圈外一只没有。

## 四、值得借的 / 别抄的

### 值得借（按对我们营地的直接价值排）

1. **拴绳回点时回满血**（`S/Actor/HammerMonster.lua:167-177`）。我们的营地怪拉出 70 米后走回点上但不回血（`ISO/raid_mob.gd:832-836`），可以「拉一下、打两下、再拉」地白磨。建议：回到 IDLE 走回 anchor 时把血回满，或者 3~5 秒内回满。
2. **营地里的稀有怪槽位 + 幸运放大**（`S/Global/HammerMonSpawnMgr.lua:195-213`）：普通权重约 990、稀有 10~25，抽中就把同类从池里拿掉（一群最多一只），有效权重 × (1 + 幸运)。可以放进 `_layout` 的固定种子里（比如 2% 的营地多一只「灵兽」或「宝怪」），用法宝的「识 / seek」放大，给固定营地加一点「值得绕路」的变化。
3. **区域独占首领 / 头目**（`S/Global/HammerMonSpawnMgr.lua:300-331`）：每片区域同时只有一只，等级取区域上限，exp ×5，寿命 300 秒。对应到我们：每个区域在深处挑一两个营地做「头目营」，同一时间只活一只，复活比精英更长（比如 300 秒），心得 ×3~5。
4. **追赶机制**（顿悟追赶，`L/HammerEpiphanyCfg.lua:17-20`）：比全服 / 房间里最高等级低很多时多给一份。联机里可以做成「比同房最高境界低 2 境以上，心得 / 撤离结算 +X%」，帮后来的人跟上队伍。
5. **组队经验系数**（`L/HammerTeamCfg.lua:18-23`）：每人拿 1 / 0.6 / 0.5 / 0.45，全队合计 1.0~1.8 倍，再加 25 米距离限制。一起打比单刷划算，但多开刷不出暴利。我们联机分心得时可以直接套这组数。
6. **按「当前一级所需」的百分比给奖励**（顿悟 1%、挂机 0.2%）：奖励自动跟着进度缩放，不用每个境界单独配表。我们的打坐表 `MED_RATE` 是按境界手配的，以后加每日 / 活动类奖励可以用这种写法。
7. **世界首领：打不死 + 个人伤害分档奖励**（`L/HammerWorldBossCfg.lua:22-`）：联机抢首领时不存在抢最后一刀，每个人按自己打了多少拿奖励。如果我们的巢穴首领要做多人版，这个规则最省事。
8. **渡劫扣血有地板**（均分扣到 10%，`S/Player/HammerPlayerGameAttr.lua:525-535`）：纯演出、不会死。我们的雷劫如果有扣血，可以对照一下。
9. 刷怪落点用 5 米网格往下打射线、再判断在不在区域里（`S/Global/HammerMonSpawnMgr.lua:278-298`）。我们 `_layout` 只用中心加四个 6 米点判断，可以考虑也给每只怪的偏移点做一次贴地 / 落水检查（营地里有怪站水里时用得上）。

### 别抄

1. **指数膨胀**（玩家每境 ×5.2、怪每 10 级 ×8，数到 1e26）：这是给挂机、付费和排行榜拉长线用的。我们刻意做了线性的 atk / hp 和「招式单位」，别回头。
2. **PvP 无封顶 + 齐次伤害公式**：属性差 k 倍，造成的伤害 ×k、承受的伤害 ÷k，击杀时间差 k² 倍。我们已有 PVP_HIT_CAP / BURST / SUSTAIN 和擂台规则，保持。
3. **玩家主动插幡刷怪 + 60 秒寿命**：适合站桩自动战斗，和我们「固定营地、可以记图、联机大家看到一样的世界」的方向相反。60 秒到点消失还会让打到一半的怪凭空不见。
4. **怪几乎没有威胁**（Lv1 怪要 120 下才打死同级玩家）：挂机取向。我们是动作战斗，怪必须能打疼人。
5. **攻防百分比的付费 / 宗门加成**（每日特权攻防 +50%、宗门宗主 +120%）：和 PvP 平衡、和「数值不碾压」的要求冲突。
6. **用战力门槛卡突破**（`RealmCfg.needBattleValue`）：逼人去刷装备 / 付费。我们是 修为满 + 破境丹 + 灵石，更贴搜打撤。
7. **每 10 级就是一个境界、200 多级**：靠每日次数（顿悟 50、挂机 600、挑战 1+1、试炼扫荡 1）把在线时长摊开，是长线 MMO 的留存设计。我们目标是普通玩家约 16~19 小时到大乘，别引入「每日次数」这类东西来拉长节奏。
