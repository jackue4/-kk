隔离快照已经开始落地这份规格：progression.gd、combat_stats.gd、num_fmt.gd 都在 18:50 改过。下面第 1 条的问题已经写进了 `CS.mob_scale(ri, lv, k)`。所有数字都用规格里的公式在本地算过，没有运行 Godot。

## 问题清单（按优先级）

**1. [严重] 首领的境界档按加成后的等级算，跨档 ×5，新手开局必死**
- **问题**：§3 的 `mob_tag(ri, lv)` 吃的是怪自己的等级。巢穴首领是当地等级 +2（raid_manager.gd:1484），天地异动首领是 +1（:1515）。草原档 [0,1] 和坠魔档 [5,7] 里，这一加就跨进下一档。
- **草原巢穴**：巢穴在 (-210,170)，离中心 270 米。按 R=480，当地是 lv3（炼气档），首领狼王变成 lv5，是筑基档。
  - 炼气1：近战一下掉 275%，震地 366%，要 1090 个招式单位才打得死。
  - 炼气3：一下 116% / 154%。
- **天地异动**：开局 110~150 秒必来一只，生成时直接 `alert()` 扑上来。
  - 出生半径是 110~300 米均匀抽（meadow_level.gd:143），61% 的出生点当地是 lv3，首领就是 lv4 筑基档。
  - 对炼气 1 / 2 / 3 级一下分别掉 236% / 153% / 98%。
  - 另有 23% 的出生点就在巢穴 200 米（LAIR_SPAWN_R，走进这个距离就刷首领）以内。
- **坠魔谷**：深度 0.1875~0.3125 是 lv18（炼虚档），天地异动刷出 lv19，是合体档，同样秒炼虚。
- **和 §10 冲突**：霸主丹的 `min_realm` 按位置的档给，结果筑基档的首领掉炼气霸主丹。
- **修法**：
  - 首领的档改成 `t = Prog.mob_tag(ri, lv - (2 if lair >= 0 else 1))`。`lair` 本来就在怪的批量包里（[.., lair, camp]），木偶两边算出来一样，仍然是纯函数。
  - `CS.mob_scale` 加一个参数 `t := -1`，`m.tag` 存这个值。
  - 修完以后：狼王对炼气1 一下 51% / 68%（旧版是 39% / 52%），天地异动 43%。

**2. [严重] 越档没有任何提示，危险判断还按线性等级**
- **问题**：区域题字的「凶险」（raid_manager.gd:1180）和信息牌变朱砂色（raid_hud.gd:665）都用 `REGIONS[r].lv > lv+2`。
- **漏报的情况**：
  - 每个境界的后两级进下一区都不报险。筑基 lv5 / lv6 进黄枫谷边缘：打兽 25.9 / 16 下，挨一下 68% / 43%。结丹 8/9 进血色、元婴 11/12 进云梦、化神 14/15 进坠魔，数完全一样。
  - 区内的档线（草原 300 米、坠魔深度 0.3125 和 0.6875）不出题字。信息牌只是 Lv.3 变 Lv.4，草原的 r.lv=1，永远不会变红。
  - 精英 / 首领名牌只写 `"%s  Lv.%d"`（raid_mob.gd:239）：差 1~2 级看着不起眼，实际是 ×5。Hammer 的做法是等级不够直接不开传送点（minLevel）。
- **修法**：
  - `tg = Prog.mob_tag(best, _level_in(best,p))`，`danger = tg > player.realm_idx`，题字写「凶险 · 此地妖兽%s期」。
  - `_update_here` 里记 `here_tag`。超过自己境界、且比上次提示过的高时 toast 一次；换区重置，和 `_sup_told` 一样。
  - 信息牌第一行把「怪物 Lv.%d」换成「妖兽 X期」，朱砂色条件改成 `tg > realm_idx`。
  - 名牌加档名，高于自己时标朱砂。
  - 新文案里不要用 易 / 毙 / 荐 / 溢 / 宁：三套随包字体都没有这几个字。

**3. [高] 出生圈外沿贴着筑基档线**
- **问题**：R=480 时 lv4（筑基档）正好从 300 米起，而出生半径上限也是 300 米。怪的仇恨半径 26 米（raid_mob.gd:26），刷怪点 100 米内就会建出来。
- **数字**：12% 的出生点离档线不到一个仇恨半径。lv4 的兽打炼气1 一下 105%，要 43 下才打得死。
- **修法**：meadow_level.gd:143 的 `randf_range(110.0, 300.0)` 改成 `(110.0, 250.0)`，不动节奏。另一个办法是 MEADOW_DEPTH_R 改到 560（lv4 从 350 米起，草原里没有 lv5），但会改到 life_sim 里筑基的刷怪深度。

**4. [高] PvP 飘字倒挂，主城和擂台的飘字没进大数**
- **PvP 倒挂**：§6 的「点数 × CS.hp(对方 lv)/100」：
  - 炼气打大乘飘 2136万，可他打同级怪只有 1018。
  - 大乘打炼气飘 453，可他打怪是 1.03 亿。
  - 飘的还是封顶前的数，对方单下实际最多掉 22 点。
- **擂台**：arena_duel.gd:691 飘的是 1~14 的气血条点数。
- **主城**：木人、刀客、剑冢首领、斗法台（enemy_dummy.gd:123、swordsman.gd:477、boss_demon.gd:642、air_foe.gd:638 非大世界时）飘的还是 8~110 × 倍率。大乘在大世界看到「1.4亿」，回试剑台只看到「110」。
- **修法**：
  - PvP 按出手方的口径显示：`minf(pts, PVP_HIT_CAP) / PVP_UNIT × CS.unit_same(my_lv)`，发出去的仍是 pts。擂台用同一个式子，换成 ARENA_UNIT / ARENA_HIT_CAP。
  - 主城几处只改显示：`dmg / CS.base(realm) × CS.unit_same(lv)`，扣血逻辑不动。

**5. [高] 缺 Hammer 的「战力变化」反馈，突破 ×2.75 那一下看不见**
- **问题**：Hammer 的战力面板（HammerUIBattleValue）是先显示旧值，0.5 秒后弹「+变化量」，再滚到新值，0.5 秒内的变化合并。

- **修法**：照心得小字（raid_hud.gd:589-625，必须挂在 `_root` 下才有随包字体）做一个 `power_chip(old,new)`，文案「战力 19.5万 → 26.8万」，0.5 秒内合并。挂点：
  - 升级：raid_manager.gd:432
  - 渡劫成功：:927、hub_hall.gd:1752
  - 换法宝：:2242 和 `_recalc_fx`
  - 主城修为精进：hall_pills.gd:179、hub_hall.gd:1592 / 1634
  - realm_banner 的 sub 可以写「境界突破 · 战力 ×2.75」。

**6. [中高] 题字字体里没有「亿」，font_check 不查题字字体**

**7. [中高] 玩家牌气血框 76 像素，从筑基1（约第 16 分钟）就被截断，规格没定方案**

**8. [中] 前两档的霸主精魄比本境极品丹还弱**
- **数字**：炼气霸主 160，只有极品炼气丹（1178）的 0.14 倍，还不如中品（294）。筑基霸主 2555，是极品（3654）的 0.70 倍。结丹以后才是极品的 2.3~35 倍。
- 草原狼王是新人打的第一只首领，掉一颗金色的「炼气霸主精魄」，却只值一颗下品丹。
- **修法**：`OVERLORD_PCT[0..1]` 改成 `[0.35, 0.10]`（得 1123 / 5110）；或者 `overlord_exp = max(realm_total×pct, pill_exp(r,3)×1.5)`。life_sim 同步改。

**9. [中] 老存档回归：丹不等值、旧名被占用、老刷怪点变死地、丹毒界面残留**
- **丹不等值**：「换成当前境界同品质的本境丹」，按占本境界修为的比例算，价值会变成原来的 0.07 ~ 13 倍不等：
  - 结丹手里的下品培婴丹（旧 t4）每颗从 4.37% 变成 0.304%。
  - 化神手里的黄龙丹（旧 t0）从 0.013% 变成 0.174%。
- **旧名被占用**：黄龙~培婴五个旧名被新的本境丹拿去用了（炼气~化神）。回来的人最好的「培婴丹」改了名，新的「培婴丹」又只有化神能吃；丹房按名字数料（raid_profile.gd:525）。
- **老刷怪点变死地**：炼虚惯去的坠魔深度 0.35（lv19）、合体惯去的 lv22，现在都高一档：43 下、一下 105%，死了法宝全丢。
- **丹毒残留**：丹毒停用了，但 tox 还存在存档里，下面这些文案会继续显示一个不存在的机制：hub_hall.gd:1565 / :1659、hall_pills.gd:174 / :248、raid_manager.gd:2305、raid_items.gd:206。
- **修法**：
  - 老丹保值迁移：`legacy_exp = PILL_EXP_OLD[t] × GRADE_MULT[g] × XP_SCALE[当前境界]`，加 `min_realm = 当前境界`，名字前加「旧·」；`pill_exp_now` 先认 legacy_exp。修为和丹乘的是同一个 XP_SCALE，进度占比原样保住。
  - VER<3 的存档读档后，主城弹一次说明（怪按境界分档、越档一击即倒、各境界宜去哪里）。
  - `Prog.tox()` 恒返回 0，删掉上面这些文案。

**10. [中] 吃不了的丹会堆在储物戒 / 随身 / 背包里**
- **问题**：
  - 一键服丹只扫仓库（hall_pills.gd:96），储物戒和随身里的本境丹一突破就作废。
  - 丹不叠格（raid_profile.gd:245 只叠灵草），仓库 60 格。
  - 一键出售不卖丹（:481）。
  - 背包满了 `_swap_out` 按价值换：草原里筑基下品（值 18）会挤掉炼气下品（12）。
  - 溢出存满上限（xp_need(top) + 下一境总量）以后，一键服丹照样扣丹，白吃。
- **修法**：
  - `count` / `_pick` 扫仓库 + 随身 + 储物戒。
  - 渡劫前（`_bottleneck`、`_break_missing`）提示「还有 N 颗X期丹，突破后不能再服」。
  - `stacks()` 和 abode_ui 的 `_stack_key` 加上丹。
  - 一键出售卖 `realm < Profile.realm()` 且没有 min_realm 的丹。
  - `_swap_out` 比较时，能服的丹价值 ×3。
  - `add_xp` 返回 used=0 时不扣丹，提示先去渡劫。

## 规格漏掉的、实现时会碰到的
- **溢出修为看不见**：`exp_ratio` 夹到 1，修为条和牌子都显示满格，玩家会以为瓶颈时服丹白吃了。加一句「已满 · 结转 +X」，别用「溢出」（缺「溢」字）。
- **带人闸让一起玩更慢**：高境界在草原 0.11 下就清一只怪，低境界的补不到刀，分到的心得全部 ×0.25，比单刷还慢，而且没有任何提示。至少被打折时给低境界一方 toast。
- **低境界队友进高区**：炼气 lv2 在黄枫谷被兽打一下掉 514%。队友名牌（remote_player.gd:123）只写 Lv，改成写境界名，在高区里标红。
- **物品说明里的回血是条上点数**：raid_items.gd:204 / 206 / 231-234 的「气血 +25」改成「气血 +25%」。丹的角标改成「筑基 +1.234万」（约 109 像素，触屏卡片 117 像素放得下）。
- **坊市**：卖的 `rpill(0,0)` / `rpill(1,0)`，结丹以上全是吃不了的货。改成按当前境界列。
- **灵田**：只出 `rpill(t,1)`（t=0..4）。炼虚以后（5.9 小时到 15.9 小时，大半游戏时间）灵田出的全是吃不了的丹。
- **字形预热**：主城 `hub_hall._float_text`（56/6）从来没预热过，手机上第一次飘「修为 +1.234亿」会顿一下。warmup.gd:304 改成预热 `"0123456789.万亿+"`。
- **文字变长**：
  - short_num 从十万起由「12万」变成「12.34万」，按钮、信息牌、结算页普遍长 3 个字符，要过一遍手机截图。
  - 信息牌第三行建议写成「压制 心得×25%」：纸条要给 Boss 血条留 320 像素。
- **战力里养 / 识没封顶**：三件 120% 养会让战力乘子多出 +0.72，在 0.5 的基础比例上是 +144%。改成 `0.2×min(养,1.2) + 0.05×min(识,1.2)`。
- **飘字写 0**：炼气在大乘档的地方打怪，每下只有约 0.03，会满屏写「0」。最少写 1。
- **大乘高等级显示**：lv48 以上修为显示「9580万亿」，lv99 是「271600000000万亿」（只有 GM / 测试档到得了）。≥1e16 时改用科学计数，或者补「京」字。
