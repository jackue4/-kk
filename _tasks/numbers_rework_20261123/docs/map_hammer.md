## 0. 先说结论（实现者最需要知道的 10 条）

1. **Hammer 的伤害公式是一次齐次的**：`dmg = atk² / (atk + 3.5·def)`（`L/HammerUtils.lua:3606-3612`）。攻防同乘 k，伤害也乘 k。所以「手感」（打几下死、挨一下掉几成）只看四个比值：玩家攻 / 怪防、怪血 / 玩家攻、怪攻 / 玩家防、玩家血 / 怪攻。**只要这四个量在同一条等级轴上同速长，数字放到万、亿都不改手感**。
2. **Hammer 的「人每境 ×5.19、怪每境 ×8」中间差的那 1.54 倍/境，全靠装备补**（装备 = 基础 × 1.15^(装备等级−1) × 1.65^(品质−1)，装备等级 = 炼器时的玩家等级 ±3，每境期望品质 +1 → 装备每境约 ×6.7）。我按源码算：**光身打同级怪要的次数从炼气 2.7 下涨到大乘 1689 下**；穿上本境界期望品质的 12 件，一直是 1~5 下；到化神装备已占总攻击的 85%~89%，大乘 95%。（第 2.6 节）
3. **我们装备会丢**，所以不能照抄「怪比人快」的落差。推荐：**人和怪用同一条 G(L)，每境 ×5.187（就是 Hammer 玩家那条：境内每级 ×1.374 = 1.1^(10/3)，突破再 ×2）**；装备只按百分比加在自己属性上、照旧封顶。用户方案里「怪每境 ×8」如果一定要在面板上看到，见 4.3 的变体 B（加一个看不见的境界倍率），我不推荐。
4. 曲线一换成指数，**等级差的含义彻底变了**：今天怪高 4 级只多 30%~40% 血；新曲线下同境内怪高 1 级 = 难打 1.5 倍，高 2 级且跨了境界线 = 打 26 下，**整整高一个境界 = 打 43 下、挨一下掉 105%**。我们的区域深度（`DEPTH_LV` 4 / 8）、各境界常打的怪等级（`REALM_MOB_LV`）都是按线性配的，必须一起改（4.3 节给了按「区域境界档」打标签的方案和逐区数表）。
5. 境界差一档：出手 ×6.6 快、挨打 ÷20，合起来强 ~130 倍 → **高境界回低区天然一刀一片，天道压制的伤害打折（`SUPPRESS_DMG`）可以直接删**；Hammer 本身就没有任何压制代码（全工程 grep「压制 / suppress」为空）。收益打折保留。
6. **战力**：Hammer = `(血×10 + 攻×25 + 防×50) × (基础比例 + 8 项百分比属性之和)`，角色自身基础比例 0.5、每件装备 1.0，只算永久层（`L/HammerUtils.lua:2440-2528`）。我按源码算，**突破战力门槛 ≈ 本境界满级的「自身 + 一套本境界期望品质装备」战力的 0.7~1.2 倍**。
7. **Hammer 普通精魄**（本境界首领必掉，`realmLimit` 精确匹配才能吃）：值占本境界总经验 3.9% → 2.4% → 0.63% → 0.16% → 0.05% → … → 大乘 0.0003%，越往后越没用；**霸主精魄**（`minRealm` 起都能吃）恒为本境界总量的 **5.15%~7.54%**（化神起才有），但到下一境只剩 0.1%~0.2%。
8. Hammer 吃丹**没有每日上限、没有丹毒、可一次吃一摞**，瓶颈时多出来的经验**不丢、突破后结转**（`S/Player/HammerPlayerGameAttr.lua:569-598, 729-787`）；我们是到瓶颈就不让吃 / 溢出丢弃，再加丹毒。建议保留我们的（节奏是按它校准的）。
9. 修为丹映射：8 个境界各一种「本境丹」（按掉落点的境界档打标签，只有本境界能吃）+「霸主丹」（巢穴首领出，≥ 本境界能吃，值 = 本境界总量 × 6%）；数值表和预算公式在 4.8 节。**修为曲线本身不照抄**（Hammer 每境 ×15.6~47，我们 ×2.74，节奏是按我们这条校准的）。
10. 显示：Hammer 用 `%.4g` + 万 / 亿 / 兆 / 京 / 垓…（`L/HammerUtils.lua:325-339`）；我们 `Prog.short_num` 只到亿、`%.1f`（`G/progression.gd:347-353`）。新曲线下大乘满级光身战力 ~71.6 亿、满装 ~272 亿，大乘 99 级要到兆，得补单位。另外 **大乘 25~99 级如果每级继续 ×1.374，99 级战力 ~1.6×10²⁰，`int()` 会溢出**（int64 上限 9.2×10¹⁸），尾巴必须放缓。

### 2.1 玩家属性

```lua
-- S/Global/HammerPropertyCfgMgr.lua:5-26
Player = { hp = 2500, attack = 1000, defend = 500, speed = 15,
    [AddHpRate] = 0.05, [CriticalRate] = 0.05, [CriticalAddRate] = 0.5, [AddDmgRate] = 0, ...四项抗性 0...,
    realmScale = 2, levelScale = 1.1, -- 最终属性=基础属性*等级系数^(等级-1）*境界系数^(境界-1）
```
```lua
-- S/Actor/HammerAttrMgr.lua:118-129  RefreshRealmLevelScale
local delta = baseValue * (realmMul) * (levelMul) - baseValue   -- 只对 2500/1000/500 这份基础值
self:ModifyAttribute(self.uin, attrType, delta, REALM_LEVEL_SCALE_SOURCE)
```

- **玩家自身** `X(L, R) = X₀ × 1.1^(L−1) × 2^(R−1)`，X₀ = 血 2500 / 攻 1000 / 防 500（比例 5 : 2 : 1）。L 是全局等级（1~309），R 是境界（1~15）。
- 只缩放基础值；装备、法相、翅膀这些是**平加的**，不吃境界 / 等级系数（`HammerAttrMgr.lua:118-135`）。
- 之后再乘「攻 / 防 / 血百分比加成」：`floor((永久+buff) × (1 + 比例) + 0.5)`（`:173-183, 692-718`）。

### 2.4 伤害公式（含暴击 / 防御）

```lua
-- L/HammerUtils.lua:3606-3612
function Utils:CalculateNativeDamage(player,target)
    local atk = Utils:GetActorAttr(player, ECustomAttr.Atk)
    local defend = Utils:GetActorAttr(target, ECustomAttr.Defend)
    -- 伤害 = 攻击力^2 / (攻击力 + 防御力 * 3.5)
    local dmg = ((atk) / (atk + defend * 3.5))*atk
```

一波飞剑（`S/Actor/HammerWeaponInst.lua:149-196`，**每柄飞剑各结算一次**）：
1. `dmg = 攻²/(攻+3.5·防)`（攻 = 玩家总攻，含装备）
2. × 攻击模式倍率 `AttackModeCfg`：弧斩 0.9×0.25 = 0.225（22 米）、突刺 0.25（18 米）、环绕 0.125（8 米）（`L/HammerConfig.lua:124-128`）
3. × (1 + 灵符共鸣增伤)
4. 先天气运元素附伤：按第 3 步的结果 × 比例 / 100，单独一跳
5. 暴击：`rand(1,1000)/1000 <= 暴击率` → × (1 + 暴伤)；**对玩家时**暴击率减抗暴、暴伤减抗爆伤（`:252-269`）
6. × (1 + 增伤)，对玩家时减抗增伤（`:271-279`）
7. × (1 + 共鸣概率增伤)
8. 吸血 = 最终伤害 × 吸血率（对玩家时减抗吸血，`:281-289`）
- 玩家默认 暴击 5%、暴伤 +50%、吸血 5%；**四种抗性只在目标是玩家时生效** → 纯 PvP 属性。
- 怪打人：引擎近战命中后改按同一个公式结算，无暴击 / 增伤（`S/Player/HammerPlayerGameAttr.lua:39-68`）。
- 攻速：每种模式基础 CD 2 秒，间隔 = 2 / (1 + 攻速)，攻速有效值钳 [0, 0.5]（`S/Actor/HammerAttrMgr.lua:705-716`）。
- **PvP 没有任何封顶**（旧报告已核实）。

### 2.5 战力（combat power）

```lua
-- L/HammerUtils.lua:2440-2455
--- 1. 基础战斗力=生命*10+攻击力*25+防御力*50
--- 2. 特殊属性加成比例=基础比例+暴击率+暴击抗性+爆伤+爆伤抗性+增伤+增伤抗性+吸血+吸血抗性
---    角色战力：基础比例=50%（forPlayer=true）  武器/装备战力：基础比例=100%（forPlayer=false）
function Utils:CalcCombatPower(hp, atk, def, extraRates, forPlayer)
    local baseBattle = (hp or 0) * 10 + (atk or 0) * 25 + (def or 0) * 50
    local spRate = forPlayer and 0.5 or 1
    for _, key in ipairs(COMBAT_EXTRA_ATTR_KEYS) do spRate = spRate + (extraRates and extraRates[key] or 0) end
    return math.ceil(baseBattle * spRate)
```
- 玩家总战力 = 「总属性减去每件装备那份」按 0.5 算 + 每件装备（装备属性 × (1 + 攻/防/血百分比)）按 1.0 + 该件词条 算，再相加（`:2476-2528`）。**装备的每点属性在战力里算两倍**。
- 只用永久层（`GetActorAttr(..., false)`），buff 不算。
- 2500/1000/500 时三项一样大（各 2.5 万）：`血×10 = 攻×25 = 防×50`，等于按 5 : 2 : 1 的属性比例把三维折成等权。
- 用途：突破门槛（`CheckBreakthroughReady`，`S/Player/HammerPlayerGameAttr.lua:657-665`）+ 排行。

**门槛和实际战力的关系（算）**——自身（基础比例 0.5 + 暴击 0.05 + 暴伤 0.5 + 吸血 0.05 = ×1.1）+ 12 件「本境界最高鼎期望品质、玩家等级」的装备（无词条）：

| 筑基 19 | 91.7 万 | 209 万 | 301 万 | 300 万 | 1.00 |

### 4.1 约束（为什么推荐「同一条曲线」）

- 齐次公式下，**人和怪的四个量必须同速**，比例才不漂。Hammer 怪比人每境多 1.54 倍是靠装备每境 ×6.7 补的（2.6 节）；我们装备会丢、而且只是百分比加成、封顶 80%，补不上。

### 4.5 战力

照 Hammer 结构，把我们的四种被动当「百分比属性」：

```
战力 = ceil( (HP×10 + ATK×25 + DEF×50) × (0.5 + 攻 + 守 + 0.2×养 + 0.05×识) )
```
- HP / ATK / DEF 用 4.2 的自身值（G 已经含境界，不要再乘 `1.1^境界`；`G/combat_stats.gd:185-188` 现在的 `pow(1.1, realm)` 要去掉）。
- 光身：炼气 1 级 3.75 万 → 大乘 3 级 71.6 亿（表见 4.2）；中等装备（攻 0.3 守 0.2）×2；满装（攻 0.8 守 0.6）×3.8，大乘 3 级 272 亿。
- 显示在 `G/player_plate.gd:58`。
- 不建议照抄「战力门槛卡突破」（旧报告已说明）；但可以用 Hammer 的规律做**区域推荐战力**：区域档 tag 的满级（L = 3·tag+3）自身战力 × (0.5 + 本区常见装备的被动) × 0.8~1.0。
- PvP 不要用这个战力做任何比较 / 封顶。

### 4.6 天道压制

- Hammer：无任何压制；靠曲线和区域门槛。
- 我们换 G 以后：高一境打本区怪出手 ×6.6、挨打 ÷20 → 已经是割草。**`SUPPRESS_DMG 0.55` 和 `sup_dmg_k()` 可以删**（`G/progression.gd:250-252`；`G/raid_manager.gd:335-344`，提示文案在 338 行写了「出手威力 ×%d%%」也要改）。

**单位和隐藏假设**
- Hammer 全程浮点：伤害不取整；装备属性 `math.ceil`；百分比读时 `floor(x+0.5)`；战力 `math.ceil`；显示时 `math.floor` 后 `%.4g`。Hammer 不存属性，只存 `playerLevel / playerExp / playerRealm / canBreakthrough`，属性每次按公式重算（`S/Actor/HammerAttrMgr.lua:647-660`）——我们也是存 lv / xp、属性现算，换曲线不用迁移属性，只有改修为单位才要迁移。
- GDScript float 是双精度，到 1e15 都精确到个位；`int()` / `roundi()` 是 int64，超过 9.2×10¹⁸ 溢出——只有大乘尾巴照 1.374 长才会碰到。
- 联机：气血同步的是 0~100 的条（`G/combat_stats.gd:9`），不会因为数字变大撑爆网络包；但凡是同步「实数伤害 / 实数血」的地方要查（不在我这块）。
- 防御公式让「谁的攻 / 防比例」决定减伤：同级减 26%；高一境打低一境减 6%；低一境打高一境减 69%。任何按「原始伤害 × 倍率」写死的地方（比如剑冢首领的 12000 血、`to_bar` 里的 `guard`）改之前要确认是在公式里还是外。
