## 1. 资源库概况与接入约定（先看这节）

- 规模：8390 个资源目录、5788 个 GLB、15049 张 PNG，约 24 GB。分类：01 主角皮肤（619）、02 NPC（14）、03 道具（705）、04 方块贴图（3676，只有 PNG）、05 生物（535）、06 待核名实体（47）、07 方块模型（2804）、`粒子特效`（10 个 Three.js 原创示例）、`2D粒子特效`（244 项像素序列帧，MIT）。
- 每个资源一个目录：`<名字>_<ID>\`，里面是 GLB + `资源说明.md`（逐文件用途、限制、动画表）。命名规律：
  - 01/05/06：`<名字>_第三人称主体_{PREFAB|OMOD}_body.glb`（01 另有 `_第一人称手部_OMOD_hand.glb`，用不上）
  - 03：`<名字>_场景道具_OMOD_body.glb`
  - 07：`<名字>_方块模型.glb`（大多**没有动画**，状态 / 开合 / 交互逻辑都不在 GLB 里）
- 动画编号（生物 / 皮肤通用）：100100 待机、100101 走、100111 跑、100105 攻击、100107 受击、100106 死亡、100109 跳。`scripts/creature_model.gd` 的 `ROLES` 已按编号认（攻击还会退而用 100108 / 100113 / 100184 / 100500 / 100201）。
- 已有的接入路子（[[miniw-creature-assets]]）：拷到 `assets/creatures/<英文名>.glb` → `--headless --import` → `raid_data.gd` 的 MOBS 里 `model / elite_model / mh / mk / fly` 指定；定妆 `-s res://_tasks/creature_gallery.gd -- 模型名…`。
- 主角皮肤路子（[[hero-skin-model]]）：`_tasks/hero_skin/strip_glb.py` 精简（只留 100100 / 100111、`--keep` 默认形态网格、`--merge`）→ `hero_skin.gd` 的 `SKINS` 加一项（骨骼名、cubes、chips、scale）→ `skin_gallery.gd` / `native_ab.gd` 验。
- **新发现的坑**：
  1. **贴图 alpha 全是 0**：`虚空博士_310101`、`骷罗_100094`、`活化生物1_100230` 的内嵌 PNG 的透明通道全为 0（RGB 正常）。导进 Godot 若材质走透明会整只看不见，接入时要强制不透明（`transparency = DISABLED`，或像 hero_skin.gdshader 那样不读 alpha）。
  2. 03 道具**全是 3D 模型、没有一张图标 PNG**（目录清单 PNG 数都是 0）。背包图标要么用 SubViewport 离线渲一遍存 PNG，要么沿用 `assets/ui` 现有图标 + 生图服务（[[image-gen-mcp]]）。
  3. 01 皮肤源文件几乎都 > 15 MB（≤ 15 MB 带剑的只有苍鸿 15.4 MB 一个擦边），必须走 strip_glb.py 精简后才能进包；先例：魔炎 30.8 → 0.52 MB、冰雪战士 33.3 → 1.5 MB。
  4. 07 方块模型「门 / 床」是物品原型姿态，不是世界摆放姿态（资源说明原话）；`蓝图-沙漠房子1~6` 是「建筑蓝图」这个物品的模型，**不是整栋房子**，别指望拿来当遗迹建筑。
  5. 多形态皮肤靠待机动画把某根骨骼缩成 0 来藏备用网格（魔炎的大个子、冰雪战士的二形态）。苍鸿的 13 把剑是不是常驻显示，要用 `python _tasks/hero_skin/glb_info.py <GLB> --anim 100100` 看「全程缩到零」一栏再定。

### 2.3 和老角色兼容的接法（建议）

- 剑修和阿拉灯共用同一套关节驱动（`voxel_hero.gd` 十五关节 + `hero_skin.gd` 每帧摆骨骼），只是 `SKINS` 多一个键 `"canghong"`，`HeroSkin.player_key()` 按所选英雄返回。联机只需多同步一个英雄 ID 字节（远端 `remote_player.gd` 已按 key 建皮肤）。
- 不播模型自带攻击动画（100105 等）——和阿拉灯一样招式全程序化，保证判定 / 手感是代码说了算，平衡好调。
- 13 把剑做成独立的 MultiMesh / 小节点给「剑阵」特效用，比挂在骨骼上省（AI 一多时骨骼摆位每帧 35–85 µs/人，见 hero-skin-model 记录）。
- **注意规避**：资源库里也有 `御剑0级_110115`（05，1.19 MB，坐骑「御剑」）——是坐骑造型，可以当剑修的「御剑飞行」载具备选，但不要和角色混用。
